✕ Traditional Solidity Casino

  • Solidity compiles only to EVM bytecode.
  • Off-chain verifier must be rewritten in JavaScript, Python, or Rust.
  • Subtle packing, overflow, or rounding differences can silently diverge from on-chain execution.
  • Players trust that the website's JS matches the contract's Solidity.

✓ FairDice in Fe 26.7.0

  • src/outcome.fe compiles directly to both EVM bytecode and WebAssembly.
  • The browser runs the house's own compiled code via fg_verify_bet.
  • Cross-target equivalence is tested in CI (roll(0x1111..., 0x5555..., 1) == 25 on both EVM & WASM).
  • Pyth Entropy V2 eliminates selective-abort withholding by either party.
